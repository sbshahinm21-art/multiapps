# Android অ্যাপ — কী আছে আর কীভাবে APK বানাবেন

## Phase 3a (ভার্সন 1.1.0, versionCode 2): Work Profile clone engine
- **Settings → Clone engine → Set up clone engine:** Android নিজের স্ক্রিন দেখিয়ে একটা আলাদা work profile বানায়। শেষ হলে **Check engine** চাপবেন।
- **ক্লোন বানানো:** Add clone চাপলে ফোনে ইনস্টল করা অ্যাপটা work profile-এর ভেতরে কপি হয়। নতুন করে কিছু ডাউনলোড হয় না।
- **আলাদা ডাটা:** ক্লোনের লগইন, ডাটা আর notification মূল অ্যাপ থেকে পুরোপুরি আলাদা।
- **খোলা:** হোম স্ক্রিনে ক্লোনে ট্যাপ করে Open চাপবেন।
- **মুছে ফেলা:** Clone settings → Delete চাপলে ক্লোন আর তার সব ডাটা work profile থেকে মুছে যায়। মূল অ্যাপের কিছু হয় না।
- **সীমা:**
  - প্রতিটা অ্যাপের ১টাই ক্লোন হয়।
  - একটা ফোনে Android একটাই work profile রাখতে দেয়।
  - Android 9 বা তার পরের ভার্সন লাগবে।
  - কিছু ফোন কোম্পানি work profile আটকে রাখে।
- **এখনো নেই:**
  - ক্লোনের ট্রাফিক proxy দিয়ে পাঠানো (Phase 4)।
  - একই অ্যাপের একাধিক ক্লোন (Phase 3b)।
- **এখনো compile হয়নি, ফোনেও চালিয়ে দেখা হয়নি।**



## Phase 2-এ যা এসেছিল
- **Home:** clone-এর গ্রিড, প্রতিটা clone-এর নাম আর রং আলাদা। যোগ করতে **Add clone** চাপবেন। কোনো clone-এ long-press করলে তার settings খুলবে।
- **Add clone:** ফোনে ইনস্টল করা অ্যাপের তালিকা থেকে বেছে নেবেন, খোঁজার ব্যবস্থাও আছে।
- **Clone settings:**
  - নাম আর রং বদলানো।
  - নিজস্ব proxy বেছে দেওয়া।
  - খোলার সময় "No proxy / Its own proxy" জিজ্ঞেস করবে কিনা।
  - notification চালু/বন্ধ আর silent করা।
  - clone মুছে ফেলা।
- **Proxies:**
  - SOCKS5 বা HTTP proxy, username/password সহ। password ফোনের Android Keystore দিয়ে এনক্রিপ্ট করে রাখা হয়।
  - **Test** বাটন proxy দিয়ে HTTPS-এ Cloudflare-এ যায়, তারপর দেখায় proxy কাজ করছে কিনা, বাইরে কোন IP দেখাচ্ছে, কোন দেশ আর কত সময় লাগল।
- **আপডেট সিস্টেম:**
  - আপনার সার্ভার থেকে নতুন ভার্সন খোঁজে, অ্যাপ খোলার সময় আর প্রতি কয়েক ঘণ্টায়।
  - APK ডাউনলোড করে। নেট কেটে গেলে যেখানে থেমেছিল সেখান থেকে আবার শুরু করে।
  - ফাইলের SHA-256 মিলিয়ে দেখে, তারপর Android-এর installer দিয়ে ইনস্টল করে।
  - Mandatory আপডেট হলে আপডেট না করা পর্যন্ত অ্যাপ ব্যবহার করা যায় না।
  - ডাউনলোড আর ইনস্টলের হিসাব Dashboard-এর Statistics-এ যায়।
- **Remote settings:** Dashboard থেকে দেওয়া announcement অ্যাপে দেখায়। আপডেট কত ঘণ্টা পরপর খুঁজবে, backup চালু থাকবে কিনা, এগুলোও Dashboard থেকে ঠিক হয়।
- **Beta program:** beta code দিয়ে যোগ দেওয়া বা বের হয়ে যাওয়া যায়।
- **Support:**
  - সাধারণ প্রশ্নের উত্তর (FAQ)।
  - অ্যাপ থেকে support ticket পাঠানো।
  - Dashboard থেকে দেওয়া উত্তর অ্যাপে দেখা আর আবার reply করা।
- **Encrypted backup:**
  - clone, proxy (password সহ) আর settings একটা ফাইলে রাখে।
  - ফাইলটা AES-256-GCM দিয়ে এনক্রিপ্ট করা, আর আপনার দেওয়া password থেকে চাবি বানানো হয় (PBKDF2, 310,000 বার)।
  - পরে ওই ফাইল থেকে restore করা যায়।
- **About:** Device ID দেখায়, ট্যাপ করলে কপি হয়।

## Phase 2-এর সময় যা বাকি ছিল
- **Clone আসলে খোলা যায় না।** ক্লোন চালানোর engine আসবে Phase 3-এ। এখন **Open** চাপলে অ্যাপ সেটা পরিষ্কার করে জানিয়ে দেয়।
- **Proxy দিয়ে ট্রাফিক পাঠানো (VPN) হয় না।** এটা আসবে Phase 4-এ। এখন শুধু proxy যোগ করা, পরীক্ষা করা আর clone-এর সাথে জুড়ে রাখা যায়।
- **Ads দেখানো হয় না।** Dashboard-এর ads settings অ্যাপ পড়ে রাখে, কিন্তু AdMob যোগ করা হবে পরে।
- **এই কোড এখনো একবারও compile হয়নি।** আমার কাজের জায়গায় Android SDK নেই। প্রথম build-এ কিছু ছোটখাটো error আসতে পারে, সেগুলো ঠিক করে দেব।

## APK যেভাবে তৈরি হবে
GitHub-এর ফ্রি build সার্ভার (GitHub Actions) কোড compile করবে, টেস্ট চালাবে, তারপর signed APK বানাবে। আপনার কম্পিউটারে Android Studio লাগবে না।

**Signing key:** `multiapps-signing-key.zip` হলো আপনার অ্যাপের স্থায়ী signing key।
- এটা কাউকে দেবেন না।
- ২-৩ জায়গায় backup রাখবেন।
- এটা হারালে পরে আর কোনো আপডেট পুরনো অ্যাপের উপর ইনস্টল হবে না। তখন সবাইকে অ্যাপ মুছে আবার নতুন করে ইনস্টল করতে হবে।

**ভার্সন নম্বর:** `app/build.gradle.kts`-এ `versionCode = 1`, `versionName = "1.0.0"` দেওয়া আছে। Release Center-এ APK আপলোড করার সময় ঠিক এই দুটো নম্বরই দেবেন।
