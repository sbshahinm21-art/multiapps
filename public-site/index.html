How to install

  1. Download the APK with the button above.
  2. Allow installs — when Android asks, tap Settings and turn on Allow from this source for your browser.
  3. Install — open the downloaded file and tap Install.
  4. Updates arrive inside the app. You do not need to come back here.

Check the file: the SHA-256 shown under the download button must match the file you downloaded.
